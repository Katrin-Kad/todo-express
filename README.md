## Сравнение площадок для базы данных

| Вариант | Оплата и хранение | Подключение и ограничения |
|---|---|---|
| Supabase · PostgreSQL | Тариф Free. 500 МБ на базу, до двух активных проектов | Подключение по TLS. Session pooler поддерживает IPv4. После недели низкой активности проект может уйти на паузу |
| Timeweb Cloud · PostgreSQL | Платная управляемая база. В настраиваемом тарифе от 10 ГБ диска. Цена зависит от конфигурации | Внешнее подключение через публичный IP, поддерживается TLS. За публичный IPv4 взимается отдельная плата |
| ИТМО Helios · PostgreSQL | Учебная база `studs` с личной схемой студента доступна без отдельной платы | Хост `pg` внутри сети факультета. К Helios можно подключиться по SSH на порту 2222 |

Условия сверены 22.11.2026 по тарифам Supabase, конфигуратору Timeweb Cloud и учебным материалам кафедры ВТ ИТМО.

Supabase выбран из-за бесплатного PostgreSQL и возможности выдать проверяющему отдельную роль для той же таблицы. Session pooler принимает соединения по IPv4, поэтому им могут пользоваться приложение на Render и проверяющий со своего компьютера. Данные лежат отдельно от сервера приложения и сохраняются при повторной публикации. Во время проверки проект Supabase должен оставаться активным. После простоя Render первый запрос может занять около минуты.

## Как устроен проект

Express принимает HTTP-запросы, сверяет токен из заголовка Authorization и проверяет входные данные. Модуль SQL обращается к PostgreSQL с параметрами отдельно от текста запроса. Это помогает корректно обрабатывать названия с кавычками и другими символами. Запросы приложения ограничены логином автора. При чтении сервер обращается к таблице, поэтому изменения проверяющего видны в API при следующем запросе.

| Путь | Содержимое |
|---|---|
| `src/app.js`, `src/validate.js` | Маршруты API и проверка параметров |
| `src/db.js` | Запросы PostgreSQL и преобразование строк в JSON |
| `public/` | Интерфейс на HTML, CSS и JavaScript |
| `sql/`, `scripts/` | Создание таблицы и ролей |
| `test/api.test.js` | Интеграционные тесты |

Интерфейс поддерживает клавиатуру и подсказывает, что произошло, через область уведомлений для экранного диктора. Поля имеют текстовые подписи, после удаления фокус возвращается к списку или полю нового дела. Тёмная тема следует настройке системы. Токен вводится в форме и хранится в пределах вкладки.

## Поля таблицы `todo.tasks`

| Поле API | Столбец | Тип и назначение |
|---|---|---|
| `id` | `id` | UUID, первичный ключ |
| `ownerLogin` | `owner_login` | Логин автора из конфигурации |
| `title` | `title` | Строка от 1 до 200 символов после обработки пробелов |
| `done` | `done` | Логическое значение, при создании `false` |
| `runId` | `run_id` | Идентификатор набора, до 64 символов |
| `createdAt` | `created_at` | Время БД, в API преобразуется в ISO 8601 UTC |

Для прямого добавления строки проверяющему достаточно указать `title` и `run_id`. Для остальных полей предусмотрены значения по умолчанию. Роли приложения и проверяющего получают чтение, добавление, изменение и удаление в учебной таблице. В Supabase включена защита строк. Две рабочие роли получают доступ через отдельные политики. Владельцем таблицы остаётся администратор базы.

## Запуск

| Компонент | Версия |
|---|---|
| Node.js | 22.23.2, используйте ветку 22 |
| Express / pg | 5.3.0 / 8.23.1 |
| PostgreSQL | 17.12 в Supabase. Локальная проверка на 14.17 |

```bash
npm ci
cp .env.example .env
# Заполнить DATABASE_ADMIN_URL, взять сертификат Supabase и сохранить как supabase-ca.crt.
npm run db:init
npm run db:role -- todo_app
npm run db:role -- todo_reviewer
# Записать DATABASE_URL, TEST_REVIEWER_URL и API_TOKEN в .env.
npm test
npm start
```

Для запуска приложения на Render достаточно `MOODLE_LOGIN`, `MOODLE_FULL_NAME`, `API_TOKEN`, `DATABASE_URL`, `DB_SSL` и пути к сертификату `DB_SSL_CA_FILE`. Команда создания роли при повторном запуске обновляет её пароль, поэтому действующий пароль надо сохранить сразу. На Render передаётся подключение роли приложения. Данные роли проверяющего и токен приложения предназначены для личного сообщения преподавателю в Moodle.
